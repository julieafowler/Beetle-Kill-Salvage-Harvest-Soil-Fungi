# Beetle-Kill-Salvage-Harvest-Soil-Fungi
Scripts for beetle kill/salvage harvesting soil fungi greenhouse paper.

Scripts, in order of use:

1. Field_ITS_Analysis
2. Field_Vegetation_Boxplots
3. Greenhouse_Vegetation_Analysis
4. Greenhouse_SoilChemistryandTexture
5. Greenhouse_16S_Analysis
6. Greenhouse_ITS_Analysis - Alpha & beta diversity, fungal guild work, etc. 
7. Greenhouse_ITS_EMFOnly_Analysis - Ectomycorrhizal fungal community only analyses 
8. Greenhouse_MAASLIN3_PlantOutcomes - 
9. Greenhouse_sPLS_PlantOutcomes - 
10. Greenhouse_DiagnosticScript_forBayesian - Assess missingness, etc. ahead of Bayesian modeling
11. Greenhouse_SoilChemistry_PCA_forBayesian - Soil PCA work for use in Bayesian modeling
12. Greenhouse_SoilChemistry_PCA_Tables - Soil PCA tables for supplemental materials, etc. 
13. Greenhouse_Bayesian_Analysis_2FactorMPBStatus - Univariate Bayesian script; non-MPB vs. MPB; predictor selection
14. Greenhouse_Bayesian_Analysis_6FactorLandUseHistory - Univariate Bayesian script; 6 land use histories; predictor selection
15. Greenhouse_Bayesian_MultivariateAnalysis_MI - Multivariate Bayesian script; uses predictors selected in univariate scripts 
16. Greenhouse_Bayesian_CoefficientTables - Multivariate Bayesian supplemental material 
17. Greenhouse_BayesianMultivariate_HypothesisFigure - Figure generation from multivariate Bayesian work 
18. Greenhouse_BayesianMultivariate_ManagementComparisonFigure - Figure generation from multivariate Bayesian work 

Files & script included in each relevant folder above.
